## 三、R119–R124 新增能力重点实测（本轮核心验证）

以下均为 2026-08-05 Docker 全栈真实触发/走查结果（截图见 PR 评论）：

### 1. 自动化订单规则（R119，对齐马帮「全自动订单」）
- `/settings/order-automation-rules`：4 条 demo 规则（低额自动确认付款、付款后自动生成采购单、签收自动通知、停用示例），启用/停用状态管理在位。
- **真实触发实测**：将 `DEMO-AT-1004`（SKU 已匹配、审单通过）批量标记已付款后，自动化引擎实时执行「付款后自动生成采购单」，`/orders/automation-logs` 出现新日志「成功：已自动生成 1 张采购单」（触发时间与操作时间一致，非 seed 预置）。
- **安全边界负样本**：`DEMO-AT-1002`（SKU 未匹配货源）执行失败并重试 3 次后阻断，日志明示原因；`DEMO-AT-1003`（审单待审/挂起）按安全边界跳过自动化。成功/失败可重试/跳过三态留痕完整，订单时间线同步标注「自动规则」。
- 对比结论：事件触发→站内动作→留痕→防环→与审单联动的闭环，已达马帮公开「全自动订单处理规则」可比水平（马帮覆盖的动作面更广，如自动选物流渠道级别细分，属增量而非结构差距）。

### 2. 买家自动消息（R120，对齐 AutoDS）
- `/customer/buyer-messages`：按订单节点（已付款/已发货/已签收/物流异常/退款）自动生成买家消息草稿，待发消息工作台 + 节点规则两个 tab，编辑/标记已发送/忽略/批量标记在位；变量缺失（如 {物流单号}）有「发送前请补全」警示。
- **口径（不夸大）**：页面顶部显式声明「当前不会自动发送到平台——平台消息通道尚未接入，系统只生成待发送草稿，绝不自动外发」，人工在平台后台发送后回填回执。这是**站内草稿 + 人工回执**模式，不是真实平台消息 API 已接通；通道凭证到位后可切换自动发送。
- 对比结论：规则×模板×节点触发的产品结构与 AutoDS 买家自动消息同构，差异仅在最后一跳的平台通道（凭证依赖）。

### 3. 选品数据面（R121）
- 选品任务 → 可上架清单：AI 评分排序、预期利润/利润率、1688 同款价与 MOQ、相似度、审核流（已批准/等待/已拒绝→生成草稿）、多选对比、CSV 导出。
- 候选「数据面板」抽屉实测：采集数据（海外在售价/30 天销量/货源采集价/采集次数）、采集价格走势图、站内同类目经营（近 90 天动销/毛利）、AI 评分明细（成本拆解：采购/物流/佣金/到手成本→预期利润率）。
- **口径**：外部数据源（TikTok Shop 热销榜/Shopee 热销榜/Amazon Best Sellers）均明示「未接入——未配置平台开放接口凭证」，不伪造大盘数据。
- 对比结论：单品决策数据面（价格走势+成本拆解+站内经营回看）达到竞品选品面板可比粒度；平台级爆款大盘为凭证/数据源依赖，非产品结构缺口。

### 4. 财务对账（R122）
- `/orders/finance-payments`：回款记录（对账状态：已结清/少款/多款自动标记、回款差异金额、渠道、手工/CSV 批量导入）+ 店铺月度费用。
- `/orders/finance-reconciliation` 对账差异工作台：订单数/未回款/少款/多款/已结清/毛利差异较大统计卡 + 状态筛选 + 实算毛利 vs 估算毛利逐单差异 + CSV 导出。
- `/orders/finance-report` 对账报表：按店铺×月份汇总回款率、费用构成（平台佣金/推广费）、实算毛利；口径声明「实算毛利 = 回款（扣手续费）− 采购实付 − 订单费用 − 店铺月度费用；未配置汇率的币种不折算、不伪造」（USD 店铺实测显示「未折算」）。
- 对比结论：回款登记→差异标记→毛利实算→报表汇总的轻量对账闭环已达店小秘公开财务清单可比水平；与平台结算单**自动**对账（拉取平台结算 API）为凭证依赖项。

## 五、正式验收前结论（本轮任务核心问题）

**结论：真实抖店 E2E 正式验收前，纯产品侧没有必须补齐的能力项。**

- 16 项矩阵 0 落后；R118 的 4 个产品差距全部实测收口；3 个原落后项复核确认为纯凭证依赖（产品闭环、契约门禁、工作台均已就绪）。
- 正式验收的唯一前置是**抖店开放平台凭证注入 + 一轮真实 E2E**（刊登/订单/库存/客服真实连通验证），属 CHARTER §3.7 资源缺口而非能力缺口。
- 若老板接受「凭证类以沙箱口径验收」，当前预验收包（R124）即为可验收状态。
- 本报告全部实测均为站内/沙箱口径，未将任何降级能力描述为真实平台 API 已接通（各节已逐项标注）。
