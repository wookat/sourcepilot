## 3. P2③ seed delivered_at 未来时间戳修正

- 根因：`demoseed/fulldemo.go` 销售单 `orderedAt = now-(48-idx*6)h`，SO-DELIVERED（idx=3）为 now-30h，而 `deliveredAt = orderedAt+48h` = now+18h（未来），误导「仅新事件不回溯」演示。
- 修正：`deliveredAt = orderedAt+24h`（now-6h，过去；仍晚于 shippedAt=+6h，链路语义不变）。订单与运单（`order_shipments.delivered_at`）同源同修。
- 回归测试（先红后绿）：新增 `demoseed/fulldemo_round174_test.go`（`TestFullDemoSeedDeliveredAtNotInFuture`），断言 seed 后所有订单/运单 delivered_at 均不在未来。修复前红（DEMO-SO-DELIVERED-0004 +18h），修复后绿。

## 4. P2④ 异常工作台 modal rethrow 触发 dev error-overlay

- 根因确认：AntD v5 `ActionButton.handlePromiseOnOk` 对 rejected onOk 会 `return Promise.reject(e)`（静态 `Modal.confirm` 无 `isSilent`），`throw e` 产生 unhandledrejection，dev server 下被 react-error-overlay 捕获盖住 toast。
- 修复（`admin/src/pages/Orders/Exceptions/index.tsx`）：「已处理」「忽略」两个 `Modal.confirm` 改用 `onOk: (close) => …` 手动控制关闭——成功 `close()`、失败 toast 且弹窗保持打开、不向外抛拒绝；「取消标记」Popconfirm（同为 ActionButton 通道）去掉 rethrow。行为等价（失败保持弹窗）且 dev 不再弹 overlay。
- 登记（不阻塞）：同一 rethrow 模式还存在于 TaskCenter/Failures、Settings/Users、Product/DraftDetail、Inventory/SyncTasks、Inventory/Alerts、Customer/ConversationDetail 共 7 处，非本轮工作台范围，建议后续批量收口。
