# R147 线1：杂项收口（裸枚举中文化 + MCP token demo seed + R146 QA 复核）

## 目标

R147 线1 杂项收口，三件事：

1. 采购单详情付款状态直出 `unpaid` 未中文化——修复，并全站扫描同类裸枚举残留一并收口（沿既有语义映射口径）。
2. MCP token 表纳入 demo seed clean/verify 覆盖（演示/测试 token 清理零残留），seed 补一条 MCP 演示 token 样本（脱敏展示口径）+ 审计样本。
3. R146 线2 QA 报告其余登记项复核：真正零数据租户空态、长租户名/大数值截断细节。

## 交付内容

### 1. 裸枚举中文化收口（Admin）

- **采购单详情**（`admin/src/pages/Procurement/Detail.tsx`）：
  - 支付状态由直出 `po.payStatus`（如 `unpaid`）改为复用 `ORDER_PAYMENT_STATUS` 映射 Tag（`unpaid`→未支付、`paid`→已支付等），未知值兜底显示原值。
  - 支付渠道由直出改为 `purchasePayChannelLabel`（`manual`→手动标记，未知渠道兜底原值，空值 `-`）。
- **订单异常详情**（`admin/src/pages/Orders/Exceptions/index.tsx`）：处理状态由直出改为 `ORDER_EXCEPTION_STATUS`（`open`→待处理、`handled`→已处理、`ignored`→已忽略）。
- **客服会话详情**（`admin/src/pages/Customer/ConversationDetail/index.tsx`）：消息 role/source/messageType 三个 Tag 由直出枚举改为中文映射（买家/客服/AI；手动录入/历史导入/平台同步/AI 建议；文本/图片/订单/系统），未知值兜底原值。
- 映射统一沉淀在 `admin/src/constants/status.ts`（与既有 `ORDER_PAYMENT_STATUS` 等同一口径），新增单测 `admin/src/constants/__tests__/statusEnumLabels.test.ts`。
- 全站扫描说明：技术态 JSON/原始数据展示（raw payload、调试信息）不属于用户可读枚举，保持原样；已有映射+兜底的页面（任务中心告警、MCP token scope、会话状态等）不重复改。

### 2. MCP token 纳入 demo seed（backend/internal/modules/demoseed）

- `fulldemo_round147.go`：seed 新增一条 `DEMO-MCP 演示只读 token`：
  - 明文随机生成（与真实创建流程同格式 `sp_mcp_ro_`+64hex），仅在内存中哈希后即丢弃；库中只落 SHA-256 哈希 + 脱敏元数据（前缀+后 4 位），带 `lastUsedAt` 演示值。
  - 审计样本：经 `operationlog.Service.WriteBackground` 写一条 `mcp_token_create` 操作日志（消息仅含脱敏展示 `sp_mcp_ro_xxxx…xxxx`，不含明文/哈希），以固定 `request_id=DEMO-MCP-TOKEN-AUDIT` 保证重复 seed 幂等（不重复写）。
- `Cleanup`：`mcp_api_tokens` 按 `name LIKE 'DEMO-%'` 硬删，零残留；`VerifyClean` 新增 `mcp_api_tokens` 残留计数检查。
- 审计样本所在 `operation_logs` 为 append-only 哈希链，Cleanup 有意保留（硬删链上行会破坏审计完整性校验）；该行本身不含任何敏感信息。
- 回归测试：`fulldemo_round147_test.go`（脱敏元数据/哈希不泄露/审计样本唯一/重复 seed 幂等/清理零残留/verify=0）。

### 3. R146 QA 其余登记项复核

- 复核项：真正零数据租户空态（大屏/报表）、长租户名/大数值截断细节。
- 结论见「验证」章节 Docker 实测部分。

## 边界与遗留

- `purchase_orders.pay_channel` 目前后端仅产生 `manual`；其它渠道值出现时兜底显示原值，接入新渠道时在 `PURCHASE_PAY_CHANNEL_LABEL` 补充。
- MCP 审计样本在 clean 后保留于 operation_logs（append-only 哈希链约束）；如需彻底清理需重建链分区，不在本轮范围。
