# R146 线1：MCP 安全加固（R145 P2 收口）

## 目标

收口 R145 线2 安全交叉审查遗留的三项 P2：① token 无过期字段；② 限流为进程内本地桶、多副本部署额度按副本数放大；③ MCP 工具调用无逐次审计（仅 `lastUsedAt` 每分钟节流更新）。基于 #295（R145 P1×3 修复，检查时仍 OPEN）分支叠加，PR → main。

## 交付内容

### 1. token 可选过期（默认不过期保持兼容）

- `mcptoken.Token` 新增可空 `expires_at`（索引）；`Create` 接受可选过期时间并校验必须在未来（`ErrInvalidExpiry`）。
- `Authenticate` SQL 与内存双重校验 `expires_at IS NULL OR expires_at > now`，过期即 401（与未知/吊销/非 readonly token 同一 fail-closed 口径，不放大可枚举信息）。
- 管理 API：`POST /api/v1/mcp/tokens` body 新增可选 `expiresInDays`（0/缺省=不过期，1-730）；列表项新增 `expiresAt` / `expired`。
- 管理页：创建弹窗新增有效期下拉（不过期/7/30/90/180/365 天）；列表新增「过期时间」列（已过期红标、≤7 天即将过期橙标）；状态列区分 已吊销/已过期/有效。readonly 403 行为不变。

### 2. 工具调用逐次审计

- 新模块 `backend/internal/modules/mcpaudit`：`mcp_tool_call_logs` 表（tenant、tokenId、tokenName、tokenMasked、tool、status、durationMs、createdAt），**不落查询参数与查询结果内容**，不落明文/哈希。
- `mcpserver` 通过 MCP SDK `AddReceivingMiddleware` 拦截 `tools/call`：成功/失败（含 tool result `isError`）均落一条；审计写入 best effort，失败仅 `slog.Warn`，不影响工具调用。
- 管理查询 `GET /api/v1/mcp/audit-logs`（租户 scope，page/pageSize/tool/status 筛选，四角色 allow）；管理页「MCP 只读接入」新增「工具调用审计日志」卡片（筛选+分页）。

### 3. 限流多副本口径（Redis 优先，降级进程内）

- `pkg/ratelimit` 新增 `Limiter` 接口与 `RedisLimiter`：Lua 令牌桶（HSET tokens/ts + PEXPIRE，原子刷新/消费/peek），key `ratelimit:<policy>:<sha256(key)>`，复用既有 `github.com/redis/go-redis/v9`（无新依赖、无新环境变量）。
- Redis 可用时（`dep.Redis` 注入）MCP 三层限流桶（每 token/每租户/每 IP 鉴权失败）统一走 Redis，多副本共享同一额度；Redis 不可用或脚本调用失败时自动降级到同策略进程内桶（**不 fail-open**），此时多副本额度按副本数放大（已在 `docs/mcp.md` / `docs/env.md` 说明）。
- `LocalLimiter.HasBudget` 增加 `ctx` 参数以对齐接口（调用点同步）。

### 4. 契约 / 权限 / 文档同步

- `tests/contracts/api-contracts.json|.test.ts`：token 创建 body、列表字段、新增 audit-logs 端点（含 forbidden 字段：plaintext/tokenHash/arguments/result），端点数 114 → 115。
- `permmatrix/matrix.json`：`GET /api/v1/mcp/audit-logs` 四角色 allow。
- `docs/mcp.md`、`docs/api.md`、`docs/env.md`、`docs/permission-matrix.md` 同步；本文件为 R146 进度记录。

## 测试

- `mcptoken/expiry_test.go`：过去时间创建拒绝；未过期可鉴权；改库到期后拒绝；无过期 token 兼容。
- `mcpaudit/service_test.go`：写入+租户隔离、tool/status 筛选、未知 status 归一为 error。
- `mcpserver/audit_test.go`：真实 MCP 会话 `tools/call` 落审计（tool/status/tenant/token 绑定、脱敏）；失败调用落 error；过期 token 入口 401。
- `ratelimit/redis_test.go`：双实例共享额度（模拟双副本）；HasBudget 不消费；Redis 不可达时降级进程内仍限流（safeenv `TEST_REDIS_URL` 门禁，未配置自动 skip）。

## 遗留与说明

- Redis 降级为每策略实例内嵌本地桶，Redis 恢复后自动回到共享额度；降级期间额度按副本数放大属已文档化的预期行为。
- 审计日志暂无保留期清理策略（表仅元数据、行窄），如量级增长可在后续轮次加定期清理。
