## 1. R157 P2：报表币种设置页删除汇率行后无未保存提示（本轮主项）

- 问题：`/settings/report-currency` 删除汇率行后「保存配置」按钮随内容收缩位移，且页面无任何未保存变更提示，连贯操作易漏点保存导致改动静默不持久化。
- 修复（`admin/src/pages/Settings/ReportCurrency/index.tsx`）：
  - 引入已保存快照（加载 / 保存成功后落盘 `snapshotOf(values)`），以 `Form.useWatch` 全量监听表单值（含 Form.List 增删行），派生 `dirty` 状态；
  - 底部固定操作区（沿用既有 sticky `tm-system-settings__footer`）在 dirty 时展示醒目 Tag「有未保存的更改，保存后才会生效」（`data-testid="report-currency-unsaved"`），保存成功或重新加载后消失。
- 回归 E2E：新增 `admin/e2e/specs/round158-report-currency-unsaved.spec.ts`（2 用例）：①删除汇率行出现提示 → 保存后提示消失且 PUT payload 精确断言、写请求恰 1 次；②编辑汇率出现提示 → 「重新加载」还原后提示消失、全程 0 意外写请求。
- 生产代码新增 `data-testid`：`report-currency-unsaved`（提示 Tag 无稳定语义选择器，最小添加）。
