## 定案：审单批量语义 = 整批 403/40303

`POST /api/v1/order-review/approve|reject` 批量中任一订单属 view-only 授权店铺时，**整批 HTTP 403（业务码 40303）拒绝、零生效**（#331/v29 口径），取代 #332/#333 期间的「200 信封 + 按行失败」行级语义：

- 实现：`ensureReviewBatchOperable` 批量前置校验（v29 已合入本分支）；行级 `EnsureStoreOperable` 保留为纵深防御；不可见/跨租户店铺订单保持逐行「订单不存在」不泄露存在性。
- 回归（先红后绿）：新增 `backend/internal/securitytests/permmatrix/r167_review_batch_semantics_test.go` `TestR167ReviewBatchWholeBatchDenied`——**混批**（operate 店订单 + view-only 店订单）整批 403/40303、两行 review_status 均不变、纯 operate 批正常放行。先红验证：临时移除批量前置校验后该测试按行级语义失败（200 + done:1，operate 行被放行——正是部分生效风险），恢复后转绿；红灯日志外置留证。
- 文档对齐：`docs/api.md`（approve 行补整批 403 口径）、`docs/permission-matrix.md`（sweep 条目改整批拒绝）、`docs/progress/R166-line2.md`（历史行级口径标注 R167 定案更新）。
- #332 PR 描述更正：已在 #332 评论区登记语义更正（该 PR 未合并，描述中「保持批量 200 envelope + 行级失败」已过时）。
