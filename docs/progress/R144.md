# R144 线1：MCP 只读入口

## 目标

以 MCP（Model Context Protocol）标准提供一个只读 server 入口，让 Claude / MCP Inspector 等客户端可以直接查询订单、库存、经营摘要与异常待办（R143 竞品对标第六节：MCP 只读入口为差异化第一杠杆）。只暴露查询工具，不暴露任何写操作；不代表任何第三方平台 API 已接通。

## 交付内容

### 后端

- **技术选型**：官方 Go SDK `github.com/modelcontextprotocol/go-sdk`（v1.7.0，发布满 7 天），Streamable HTTP、stateless、JSON response，直接以 gin handler 挂载 `POST /api/mcp`，复用现有 service/DB，不引入独立服务进程。
- **`backend/internal/modules/mcptoken`**：租户级只读 API token 管理。
  - 格式 `sp_mcp_ro_` + 64 hex（32 随机字节）；明文仅创建响应返回一次，库中只存 SHA-256 哈希（`mcp_api_tokens` 表）。
  - 列表脱敏展示（前缀+后 4 位）；吊销幂等且立即生效；创建/吊销写操作日志（resource=`mcp_token`）。
  - 管理路由 `GET/POST /api/v1/mcp/tokens`、`POST /api/v1/mcp/tokens/:id/revoke`，走统一 JWT 鉴权 + 租户 scope + ReadonlyWriteGuard。
- **`backend/internal/modules/mcpserver`**：MCP 入口 `POST /api/mcp`。
  - Bearer token 鉴权（恒定时间比较、格式先验校验、fail closed），revoked 即 401。
  - 每 token 令牌桶限流（`MCP_RATE_RPS` / `MCP_RATE_BURST`，默认 5/10），超限 429 + Retry-After。
  - 4 个只读工具，全部强制 token 所属租户 scope：`orders_query`、`inventory_query`（经 products 租户归属 join）、`report_summary`（按币种已支付销售额，不折算）、`exceptions_pending`（复用 orderexception service）。
  - 输出脱敏：无密钥/密码/内部 UUID，客户姓名仅保留首字符。
- **配置**：`MCP_ENABLED`（默认 true，false 时入口不注册）、`MCP_RATE_RPS`、`MCP_RATE_BURST`。

### 前端

- 设置页新增「MCP 只读接入」（`/settings/mcp-tokens`）：创建（一次性明文弹窗 + 复制）、脱敏列表、吊销（Popconfirm）、readonly 账号禁用写入口。
- `admin/src/services/mcpTokens.ts` 服务封装。

### 安全与权限

- 权限矩阵登记：tokens 读路由四角色 allow，写路由 readonly forbid；`POST /api/mcp` 登记 `probe: false`（非 JWT persona，模块测试覆盖）。
- 测试：`mcptoken/service_test.go`（哈希存储、明文不落库、格式/篡改/吊销 fail closed、租户隔离、tenant 0 兼容）、`mcpserver/server_test.go`（401 缺失/非法/已吊销、工具面恰为 4 个只读工具、orders/report/inventory 租户隔离与脱敏、429 限流），经 MCP SDK 真实客户端握手调用。

## 边界与遗留

- token scope 目前仅 `readonly` 一档、绑定租户全量店铺；如需按店铺细分授权，可在 `mcp_api_tokens` 上扩展 store grants（结构已预留 scope 字段）。
- 报表摘要金额为订单原币种合计，不做汇率折算（与深度报表「未折算」口径一致）。
- MCP 入口是本系统自建查询入口，不代表第三方平台 API 已接通。
