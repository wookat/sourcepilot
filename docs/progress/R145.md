# R145 进度附录

## 线 1：实时经营大屏（feat/round145-dashboard-screen）

竞品对标 R143 第六节把「实时经营大屏」列为差异化第二杠杆：R130 起聚合已下推 SQL，只差展示层。本轮补齐展示层与单次聚合接口。

### 后端

- **新增 `GET /api/v1/dashboard/screen`**（`operationdashboard` 模块 `screen.go`），单次请求返回大屏全部数据：
  - `today`：今日订单数（scoped COUNT）；已付款单数 / 销售额 / 毛利 / 毛利率复用 `/reports/profit` 的 #276 SQL 下推聚合口径（`reports.ProfitReport` shop 维度 Summary），缺汇率或成本时返回 null，不伪造 0。
  - `todos`：订单生命周期待办五类（待收款确认 / 待采购 / 待发货 / 在途待送达 / 订单异常），每类一条 scoped COUNT，异常走 `orderexception.DashboardSummary`。
  - `funnel`：近 7 天订单状态流转漏斗（新建 → 已付款 → 已生成采购 → 已发货 → 已送达），单条 `SUM(CASE …)` 分组 SQL，无逐行扫描。
  - `trend`：近 24 小时逐小时订单 / 已付款趋势，`date_trunc('hour')` 分组一条 SQL，Go 侧补齐空桶。
  - `alerts`：open 任务告警（task_alerts）+ 断货 / 低库存 SKU 合并为滚动告警列表（各有限额，合计 ≤20 条）。
- **scope 不回退**：所有订单查询经 `Scope.applyTenantColumn` + `applyShopColumn`（operator 仅授权店铺；无授权店铺 fail closed `1 = 0`）；毛利经 `adminperm.ApplyTenantScope/ApplyStoreScope`（与利润报表同一路径）。
- **权限矩阵登记**：`permmatrix/matrix.json` 新增 `GET /api/v1/dashboard/screen`，四 persona 均 allow（GET 只读，readonly 天然适配）。
- 测试 `screen_test.go`：tenant+shop 谓词、空店铺授权 fail closed、24 桶补齐、漏斗/待办键序契约。

### 前端

- **新页面 `/dashboard/screen`「经营大屏」**（`admin/src/pages/Dashboard/Screen`）：
  - 深色大屏主题默认（scoped `ConfigProvider` darkAlgorithm），可切浅色，主题与刷新间隔本地记忆。
  - 今日订单 / 销售额 / 毛利 / 告警四张 KPI 大数字卡（`clamp()` 字号自适应 1920 → 768）；未折算币种与「缺少汇率或成本」明示。
  - 待办五类计数卡（可点击跳转对应工作台）、订单状态漏斗（Column）、近 24h 趋势（Line，懒加载 `@ant-design/plots`，无新依赖）、告警滚动列表（>6 条时 CSS ticker 循环滚动，hover 暂停）。
  - 自动刷新轮询：15/30/60 秒或暂停，可配置；单接口刷新无 N+1。选择轮询而非 SSE/WS：数据为分钟级经营聚合，30s 轮询已满足投屏演示且零新增基础设施；如后续需要秒级推送可在该单接口上平滑升级 SSE。
  - 全屏按钮（Fullscreen API）适配投屏；1920 主视口，1440/1280/1024/768 优雅降级不溢出。
- `admin/src/services/dashboard.ts` 新增 `queryDashboardScreen` + DTO 类型；契约登记 `tests/contracts/api-contracts.json`。

## 边界与遗留

- 毛利口径与利润报表一致：依赖租户手工汇率表与参考进价，缺配置时大屏显示「—」并提示，不做估算。
- 漏斗固定近 7 天、趋势固定近 24h；如需可配置窗口可在 query 参数上扩展（scope 逻辑不变）。
- 告警滚动为纯 CSS 循环（无 JS 定时器），减少投屏长时运行内存压力。
