# R152 线2：买家消息多语言模板（跨境多语种买家）

## 目标

复评 v7（`docs/COMPETITIVE_BENCHMARK_R151.md` 路线②）建议项：话术/消息模板支持多语言变体，买家消息草稿按订单/店铺目标语言选择变体，人工确认发送口径不变（绝不自动外发）。

## 交付内容

### 1. 模板多语言变体（backend/internal/modules/customerchat）

- 新表 `customer_reply_template_variants`（`tenant_id + template_id + language` 唯一，变体正文 ≤4000 字符）；`customer_reply_templates` 新增 `default_language`（缺省 `zh-CN`，既有 `content` 即默认语言正文，历史数据零迁移兼容）。
- 语言表可扩展（`template_lang.go`）：`zh-CN/en/es/pt/fr/de/it/ru/ja/ko/th/vi/id/ms/ar`；变量占位符 `{变量}` 口径与默认正文一致。
- 模板 API 新增 `defaultLanguage`、`variants`（传 `variants` 时事务内全量替换）；校验语言合法/不重复/内容非空；按租户隔离，跨租户 404。

### 2. 草稿语言选择与切换（buyermsg）

- 生成草稿时按优先级推断目标语言：①订单 `RawData` 收货地国家（`order_country`）→②店铺默认语言（`shop_language`）→③店铺平台（`platform`）→④无法推断回退模板默认语言并标 `fallback`；推断出语言但缺变体时用默认正文标 `no_variant`。
- 草稿 DTO 新增 `language` / `langSource`（含 `manual`），语言选择全程可解释。
- 新端点 `POST /buyer-messages/drafts/:id/regenerate`（body `{language}`）：仅 `pending`，按所选语言重填订单变量重新生成，成功后 `langSource=manual`；只修改草稿，不触发任何外部发送；写权限沿 `adminperm.CanWriteCustomer`（readonly 403），跨租户 404，记 operation log。
- 幂等/不覆盖既有草稿/人工确认发送等既有口径不变。

### 3. Admin UI（全中文管理界面，模板正文可为外语）

- 话术模板页：语言列展示默认语言+变体语言标签；编辑弹窗支持默认语言选择与语言变体增删改，带变量占位符指引。
- 待发消息工作台：语言列展示语言与推断来源（含「无法推断，已回退默认语言」「缺该语言变体，已回退默认语言」标注）；编辑弹窗可选语言「按所选语言重新生成」，明确「仅改草稿，不会向买家发送」；readonly 全部写控件禁用。

### 4. Demo seed（clean/verify 覆盖）

- 话术模板补英/西/葡变体样本；正样本 `DEMO-BM-1005`（US→en）、`DEMO-BM-1006`（BR→pt），负样本 `DEMO-BM-1001`（无国家→zh-CN fallback）。
- Cleanup/VerifyClean 覆盖 `customer_reply_template_variants` 零残留，重跑幂等。
