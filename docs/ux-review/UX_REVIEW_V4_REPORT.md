## 二、真实卖家动线评价

### 1. 迁移导入向导（店小秘/马帮 → 贸灵）

- 完整跑通：上传 CSV（3 行，1 行缺商品名称）→ 列映射 → 校验报告（可导入 2 行/问题 1 行，问题行有行号+原因）→ 确认导入 → 结果页（成功 2 · 失败 1 · 重复跳过 0，可下载错误行报告）→ 导入历史出现「部分成功」记录，支持错误行下载。
- 上手顺畅：四步 Steps 清晰，格式/大小/行数限制在上传页写明；必填字段未映射时黄条警示并阻断校验；375 视口映射表格可横向滚动、无溢出。
- 摩擦点：常见导出列名「标题」未被自动映射为「商品名称」，卖家需手动选择来源列（见 P2-1）。

### 2. 发货动线（订单 → 批量发货 → 打印）

- 步骤数合理：订单列表勾选（1）→ 批量发货（2）→ 粘贴「订单号 运单号 [物流商]」多行文本（3）→ 提交（4）。弹窗内说明覆盖了匹配规则、失败提示与「手工扣库存」策略，缺省物流商可下拉选择，375 视口完整可用。
- 打印拣货/发货单：从订单列表勾选进入 /orders/print，单据含收件人、拣货明细（规格/编码/数量）、物流段与「面单粘贴处」，未发货订单提示「发货后可重新打印带运单号版本」，实用性好；打印时隐藏后台外壳（R91 已修）。
- 问题：单据「平台」直出英文/内部枚举（tiktok / manual / douyin_shop），仓库人员看到的是内部码（P1-2，本轮已修复）。

### 3. 多币种

- 汇率设置页：本位币 + 手工汇率表，「1 单位原币 = 多少本位币」含义和示例（USD 填 7.13）讲得清楚；375 视口无溢出。
- 报表折算：USD 未配汇率时顶部黄条提示并链接到设置页，闭环引导好；但合计卡标题写「销售额折算合计（CNY），含未折算币种」，而后端口径是未折算金额**不计入**合计（USD 188.49 未计入 171.40），文案与口径相反，卖家会误读金额（P1-1，本轮已修复）。
