## 三、问题清单

### P1（本轮直接修复，随本报告 PR）

| 编号 | 页面 | 问题 | 修复 |
| --- | --- | --- | --- |
| P1-1a | 登录/注册页 | 登录/注册两个 `<Form>` 在同一 JSX 位置三元切换，React 复用同一组件实例导致 antd Form 始终绑定初始 `loginForm` store：注册页输入的邮箱不在 `registerForm` 中，「获取验证码」请求体缺 `email` 字段 → 后端 400 `invalid body`（英文）→ 前端兜底「发送失败」 | 两个 `<Form>` 增加独立 `key`（login/register）强制重挂载，各自绑定正确 form 实例；补 E2E 回归 `round120-register-send-code.spec.ts`（断言请求体含 email 且 503 中文指引透出） |
| P1-1b | Docker 部署（admin nginx） | `admin/nginx.conf` `proxy_intercept_errors on` + `error_page 502 503 504` 把后端**业务 503**（如 50301「邮件服务未配置…」可操作指引、AUTH_STATE_UNAVAILABLE 重试契约）整体替换为「系统升级维护中，请稍后重试」，V6 P1-1 的前端透传修复在 Docker 部署下被网关层吞掉 | `error_page` 仅保留 502/504（真网关不可达），503 业务响应透传；Docker 实测注册页现可看到完整 SMTP 配置指引 |
