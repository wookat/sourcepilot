# 日常运营操作手册（1688 人工下单过渡模式）

本手册面向店铺运营者，覆盖「选品 → 上架 → 出单 → 采购 → 发货」的日常操作。适用于当前 1688 降级模式：系统生成采购清单，运营者人工到 1688 下单付款并回填单号。

部署方式见 [docker-deployment.md](docker-deployment.md)；环境变量见 [env.md](env.md)。

## 前置检查（一次性）

1. 完成 Docker 部署并登录 Admin（`http://<服务器>:8000`）。
2. 确认 `.env` 中 `ADMIN_BOOTSTRAP_TENANT_ID=1`（选品任务依赖租户 ID > 0）。
3. 系统设置中配置 AI Provider（可选；未配置时选品打分自动走确定性规则兜底）。
4. 系统设置中确认汇率、平台佣金率、物流费模板、退货率等利润参数符合当前店铺实际。

## 每日流程

### 1. 选品（10–20 分钟）

1. 进入「选品任务」，新建任务：粘贴候选商品（海外在售价）或关键词，每行一条。
2. 等待 worker 打分完成（任务状态变为 success）。
3. 查看「可上架清单」：按预期利润 / 利润率 / AI 评分排序，通过或驳回候选。
4. 对通过的候选执行「转商品草稿」。

### 2. 上架

1. 在商品草稿中完善标题 / 描述（可用 AI 优化）与图片。
2. 按平台流程刊登（当前平台打通为预留能力时，导出资料后到平台后台手动上架）。
3. 上架后到「货源档案」为商品绑定 1688 货源与 SKU 映射（进价、链接、库存参考）。

### 3. 出单与采购（每日固定时间）

1. 进入「采购协同」，从已付款销售订单生成采购单（系统按主货源聚合）。
   - 若提示「商品没有主货源」，先回货源档案绑定货源再重试。
2. 导出 CSV（含 1688 链接、offerId、SKU、数量、参考价）。
3. 逐条到 1688 下单并付款（收货地址填云仓/中转仓）。
4. 回填 1688 订单号 → 状态变为「已下单」；付款后标记付款。

### 4. 发货与跟踪

1. 1688 卖家发货后，回填运单号 → 状态「已发货」。
2. 货到云仓签收 → 状态「已签收」，由云仓完成跨境段发货。
3. 所有状态流转均有审计记录，可在采购单详情查看。

## 每周维护

- 「货源档案」中刷新报价：关注涨价预警与断货切换建议，必要时手动切换主货源。
- 复盘可上架清单的通过率与实际出单数据，回调利润参数（汇率、物流费、退货率）。
- 备份数据库（`docker compose -f docker-compose.full.yml exec postgres pg_dump ...`）。

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 选品任务一直 pending | 管理员租户 ID 为 0，worker 拒绝任务 | 确认 `ADMIN_BOOTSTRAP_TENANT_ID=1` 后重建管理员，或按 P4.1 迁移文档修正租户 |
| 生成采购单被拦截 | 商品未绑定主货源 | 到货源档案绑定货源与 SKU 映射 |
| AI 评分显示为规则兜底 | 未配置 AI Provider 或调用失败 | 系统设置中配置可用的 AI Provider |
| 报价刷新无变化 | 当前为 mock 报价服务 | 属预期；接入 1688 官方 API 后自动切换真实报价 |
