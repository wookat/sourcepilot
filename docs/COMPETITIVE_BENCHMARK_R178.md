## 三、三个重点问题的回答（本轮核心）

### 1. 维护期修复在 main 上是否零回退？——**是（已合入部分全绿；R174–R177 增强尚未合入）**

- 已在 main 并实测零回退：40303 文案统一（5 类写路径均返回「店铺无操作权限」）、异常 handle/ignore **先 scope 后 body**（view-only + 合法 body 仍先答 40303）、settings 加密+脱敏基线（密文落库、`sk-****1234`）、MCP/开放 API token 用途分离、审计落库。
- **尚未合入**（OPEN PR，按诚实口径不计入位次）：modal onOk 失败保持弹窗（#349）、modal rethrow 全站收口（#352）、迁移导入租户闭合+settings 加密粘性（#353）、settings 敏感 key 服务端注册表（#355）、modal 防重复提交 P1（#356）及三份报告类 PR（#348/#350/#351/#354）。**#348–#356 共 9 个 PR 积压，建议线1 尽快按序合入**，否则下次复评仍只能按 main-R173 口径评估。

### 2. 竞品 AI/MCP/自动化面是否出现新结构性缺口？——**无新结构性缺口，竞品身位继续按既有方向加厚**

- AutoDS：MCP 从发布（7-16）→ 多店铺教程（8-05：eBay/Shopify/WooCommerce 单会话管理，「搜品、建 listing、改价、看店铺表现」明确含写）→ 官方 feature 页常驻（「If you can chat, you can run a store」「Bulk changes, simplified」）。**对话式写已是其常态产品叙事**，非实验特性。
- 店小秘：8-03 美客多全托管批量刊登（140+ 平台采集→批量编辑→AI 优化→五站点一键发布→数据搬家铺货）。属**平台覆盖+内容生产**组合拳，无 MCP/对话式/开发者 API 公开动作。
- 马帮：TikTok Shop 美区 2026 Q1 本土店+跨境店双赛道官方认证、拉美 Developer Summit 获奖。属**平台覆盖/合规**侧，开发者体系无结构性变化。
- 结论：我方「只读 MCP+开放 API+审计+店铺级分权」身位未被追平（店小秘/马帮 MCP 仍为零）；唯一持续扩大的差距仍是「对话式写」——竞品已量产运营 vs 我方停在决策材料（D1–D4 未勾选）。
