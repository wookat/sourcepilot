# 迁移导入指南（店小秘 / 马帮 → 本系统）

> Round 92。从店小秘（DianXiaoMi）或马帮（MaBang ERP）迁来的卖家，可以把两边导出的**商品文件**与**历史订单文件**通过「设置 → 迁移导入」向导批量导入本系统，无需手工逐条录入。

## 入口

- 设置 → 迁移导入（`/settings/migration`）：导入向导 + 导入历史。
- 商品 → 商品草稿页工具栏「迁移导入」按钮（预选商品导入）。
- 订单 → 批量导入订单弹窗中的「上传店小秘 / 马帮文件导入」（预选订单导入）。

## 向导流程

1. **上传文件**：选择导入类型（商品 / 历史订单），上传 CSV 或 XLSX（单文件 ≤10MB，单批 ≤1000 数据行；超出请拆分文件分批导入）。
2. **列映射**：系统按表头自动识别来源格式（店小秘 / 马帮 / 自定义）并自动猜测列映射；可手工调整每个目标字段对应的来源列。归属店铺**必选**；operator 角色只能选择被授权可操作的店铺。
3. **校验报告**：逐行报告必填缺失、批内重复、非法值（行号 + 问题描述）；有问题的行不会入库，其余行可继续导入。
4. **确认导入**：
   - 商品：按「商品名称」聚合，同名多行合并为一个**商品草稿**的多个规格（SKU）；系统中已存在的 SKU 编码按「重复」跳过。
   - 订单：按「订单号」聚合，同单号多行合并为一张订单的多个商品行；系统中已存在的订单号按「重复」跳过；来源状态映射为本系统状态。
5. **幂等重传**：同一文件（按内容 SHA-256 识别）重复提交不会重复建档，直接返回首次导入的批次结果。

## 导入历史与错误行

「导入历史」标签页可查看每批导入的结果（成功 / 部分成功 / 失败、成功行 / 失败行 / 重复行数），并可**下载错误行报告**（CSV，含行号、状态、字段、错误信息与原始数据），修正后可将错误行另存为新文件重新导入。

> QA / 演示环境清理：`pnpm seed:demo:full:clean` / `verify`（可加 `-- -prefix MB-` 等自定义前缀）会一并清理迁移导入产物——前缀文件名/批次标识或导入到前缀店铺的 `import_jobs` 及其错误行，以及由导入创建的带前缀商品草稿（标题或 SKU 编码带前缀）与订单（订单号带前缀）；真实导入历史不受影响。

## 支持的来源列（字段别名）

系统按表头文字自动匹配，中英文均可；识别不了的列可在「列映射」步骤手工指定。

| 目标字段 | 常见来源列名 | 必填 | 校验 |

| SKU 编码 | SKU / 商品SKU / 库存SKU / SKU编码 | 否 | 批内不可重复；已存在的按重复跳过 |

| 成本价 | 成本 / 成本价 / 采购价 / 采购参考价 / Cost | 否 | 非负数字 |
| 库存数量 | 库存 / 库存数量 / 数量 / Quantity / Stock | 否 | 非负整数 |
| 币种 | 币种 / 货币 / Currency | 否 | 3 位字母代码（CNY / USD 等） |

## 格式假设说明

店小秘与马帮均未提供公开可下载的官方导出模板（导出列可在其后台自定义），本功能按公开帮助文档与页面资料构造兼容格式：

- 店小秘：帮助中心（help.dianxiaomi.com）订单管理章节描述的「自定义导出 Excel」，典型列为订单号、店铺、商品名称、SKU、规格、数量、单价、订单金额、收件人、国家、地址、状态、时间等。
- 马帮：官网订单导入映射页（global.mabangerp.com/whole-order-import-map.php）列出的字段：订单号、交易单号、店铺、客户姓名、电话、国家、省、市、邮编、邮寄地址、付款时间、商品编号/名称/数量/单价、订单金额、物流方式、货运单号、状态、仓库等；商品文件典型列为商品名称、成本、SKU、仓库、数量。

因此：**列名允许任意变体**（按别名自动猜测 + 手工映射兜底），不强依赖任何一家的固定模板；两家导出的中英文表头均在别名表覆盖范围内。样例文件见 `admin/e2e/fixtures/files/`（合成数据，不含真实卖家信息）。
